# 微信商户申请通过后，查看配置

请用商户超级管理员账号打开 [微信支付商户平台](https://pay.weixin.qq.com/)。大部分资料都在 **账户中心 → API安全**；有些页面会显示为“账户中心 → 账户设置 → API安全”。

## 需要准备的资料

| 资料 | 点哪里、怎么拿 |
|---|---|
| 商户号（MchID） | 申请成功的通知邮件里有。也可在“账户中心 → API安全 → 商户API证书 → 申请证书”弹窗里看到商户号和商户名称。 |
| 小程序AppID | 打开 [微信公众平台](https://mp.weixin.qq.com/)，登录这个小程序，点“开发与服务 → 开发管理 → 开发设置”，复制“AppID（小程序ID）”。 |
| 商户API证书及私钥 | 商户平台“账户中心 → API安全 → 商户API证书 → 申请证书”（已有证书时从“管理证书”进入）。按下方步骤申请，保存生成的整个证书文件夹。 |
| 商户API证书序列号 | “账户中心 → API安全 → 商户API证书 → 管理证书”，复制对应证书的序列号。必须与交给开发人员的证书属于同一份。 |
| API v3密钥 | “账户中心 → API安全 → 解密回调 → APIv3密钥 → 设置”。先请开发人员生成32位随机字母数字，再按页面提示设置并保存。**设置后不能查看，只能重新设置。** |
| 微信支付公钥文件和公钥ID | “账户中心 → API安全 → 微信支付公钥 → 申请公钥”。申请后下载公钥，并复制详情页的公钥ID，通常以 `PUB_KEY_ID_` 开头。 |

本项目配置模板默认使用“微信支付公钥”方式

## 证书怎么申请

1. 在“商户API证书”页面点“申请证书”，下载并安装微信官方证书工具。
2. 打开工具，选一个自己能找到的保存文件夹，填入商户号、商户名称。
3. 工具生成“证书请求串”，复制到商户平台，按提示完成管理员验证。
4. 商户平台给出“证书串”，复制回证书工具，完成申请。
5. 点“查看证书文件夹”，把整个文件夹妥善保存。开发人员主要需要 `apiclient_cert.pem`（证书）和 `apiclient_key.pem`（私钥）。

**私钥在申请证书的电脑上生成，不能从后台找回。** 丢失时须与开发人员商量重新申请，不能只下载一张证书代替。

## 还要把商户号和小程序关联

1. 商户平台：“产品中心 → APPID授权管理 → +关联AppID”，填写上面的**小程序AppID**，提交申请。部分页面名称为“APPID账号管理”。
2. 微信公众平台：登录小程序，点“微信支付 → 商户号管理”，确认待关联商户号；也可按“公众平台安全助手”的通知确认。
3. 商户平台：“产品中心 → APPID账号管理 → 我关联的APPID账号”，检查是否已经绑定。

## 交给开发人员的清单

- 商户号、小程序AppID。
- 商户证书文件夹、对应的证书序列号。
- 自己保存的API v3密钥。
- 微信支付公钥文件、对应的公钥ID。
- 小程序绑定商户号的结果，以及已获批支付产品/经营场景的结果。

密钥和私钥请通过与开发人员约定的私密方式交接，不要发到客户群、公开文档、代码仓库或小程序前端里。

服务器的HTTPS和支付回调地址由开发人员配置。项目已记录域名 `lsxt.gank.chat`，计划支付回调为 `https://lsxt.gank.chat/api/v1/webhooks/wechat/payments`，退款回调为 `https://lsxt.gank.chat/api/v1/webhooks/wechat/refunds`；域名记录不代表HTTPS已部署。

资料齐全后，还需要检查支付产品是否获批，再完成真实下单、付款、回调和退款测试。课程/会员属于数字商品，不能只凭商户申请通过就认定该支付场景可用。
