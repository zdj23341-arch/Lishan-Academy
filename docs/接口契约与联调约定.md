# 接口契约与联调约定

> 当前协作版本：v1.1（2026-10-08）。第12、13节补充负责人分工与经营数据字段；原业务原则继续有效。

这是小程序、管理后台和后端共同使用的设计基线。阶段 0 后端按本文件生成 OpenAPI，前端据此建立 DTO 和模拟数据。接口字段或状态变更必须同时更新本文件、OpenAPI 和前端类型；不得各端自行解释。接口当前实现情况以工程与联调记录为准。

当前后端接口以开发环境 /v3/api-docs 和源码为准，工程入口见 [后端说明](../backend/README.md)。本文件记录字段和联调基线，真实渠道与真机状态须单独验收。

## 1. 通用格式

请求前缀为 `/api/v1`。所有响应使用：

```json
{
  "code": "OK",
  "message": "",
  "data": {},
  "requestId": "req_xxx"
}
```

列表 `data` 使用：

```json
{ "items": [], "page": 1, "pageSize": 20, "total": 0 }
```

金额只传整数分，例如 `¥39.90` 为 `3990`；比例使用基点，例如 12.5% 为 `1250`；时间使用 ISO-8601 带时区字符串。ID 使用字符串，前端不得依赖数据库自增数值的格式。

## 2. 错误码

| 错误码 | 前端处理 |
|---|---|
| `UNAUTHORIZED` | 清除登录态，保留一次目标路由后跳登录 |
| `FORBIDDEN` | 显示无权限，不重复请求 |
| `NOT_FOUND` | 显示内容不存在或已下架 |
| `VALIDATION_ERROR` | 展示字段级错误 |
| `ORDER_STALE` | 刷新订单预览，提示价格/库存已变化 |
| `INSUFFICIENT_STOCK` | 回到确认页刷新库存 |
| `ENTITLEMENT_EXPIRED` | 显示课程/会员到期入口 |
| `FILE_NOT_READY` | 显示文件处理中，允许稍后重试 |
| `IDEMPOTENCY_CONFLICT` | 同键请求体不同，查询原动作并提示冲突，不能覆盖旧请求 |
| `PAYMENT_PROCESSING` | 显示处理中并刷新订单，不直接判定失败 |
| `WITHDRAWAL_NOT_READY` | 显示商家转账未开通，不展示成功状态 |
| `EXTERNAL_SERVICE_UNAVAILABLE` | 保留业务状态，显示稍后重试 |

## 3. 写操作约定

创建订单、支付、退款、发货、提现请求头带前端生成的 UUID `Idempotency-Key`；同一业务动作重试复用原值。后端以 actor+scope+key 唯一，保存请求摘要和业务结果，同键不同请求体返回 `IDEMPOTENCY_CONFLICT`。幂等记录至少保存 7 天；订单号/渠道单号/流水业务键永久唯一，不依赖记录过期来允许重复支付。

前端按钮点击后立即禁用；超时只查询原业务结果，不盲目重新创建。后端回调和定时任务也必须使用外部单号唯一约束。

## 4. 核心枚举

```text
ProductType: COURSE | BOOK | MEMBERSHIP
OrderStatus: PENDING_PAYMENT | PAID | COMPLETED | CANCELLED
FulfillmentStatus: NOT_REQUIRED | PENDING_SHIPMENT | SHIPPED | RECEIVED
RefundStatus: NONE | REQUESTED | RETURN_REQUIRED | RETURNING | PROCESSING |
              PARTIAL | FULL | REJECTED | FAILED
EntitlementType: COURSE_VIEW | MEMBER_PAPER
FileFormat: DOC | DOCX | PDF | JPG | JPEG | PNG | WEBP
CommissionStatus: PENDING | AVAILABLE | PARTIALLY_REVERSED | REVERSED
WithdrawalStatus: REQUESTED | PROCESSING | UNKNOWN | USER_ACTION_REQUIRED | SUCCEEDED | FAILED | CLOSED

```

增加枚举时后端保留未知值的兼容错误信息，前端对未知状态显示通用状态，不崩溃。

## 5. 关键接口示例

### 首页

`GET /home` 返回已发布 revision 和 banners、shortcuts、sections；数组按后端顺序展示。公开轮播/封面可以是公开 CDN URL；付费视频/试卷文件才需要鉴权短时 URL。发布版要求 3 张轮播和 8 个入口，后台草稿可暂时不完整。目标下架时前端显示“内容已下架”，后端不放开购买。

### 订单预览

`POST /orders/preview` 请求只传 productId、quantity、addressId（数字商品为空）；响应返回 quoteId、商品快照、库存、运费、payableAmountFen、expiresAt。首期没有优惠券输入。`POST /orders` 只提交 quoteId 与可选 attributionToken，重新计价和校验；客户端不能自报价格、比例或分销员。

### 课程播放

`GET /courses/{courseId}/chapters/{chapterId}/play-url` 有效课程权益或公开试看章节可以成功；响应中的播放 URL 有短时效，前端不得持久化。

### 会员文件

`POST /papers/{paperId}/files/{fileId}/authorize` 返回用途为 `PREVIEW/DOWNLOAD` 的短时授权；服务端按有效会员权益和文件状态校验，Word、PDF、图片共用权限规则。

### 提现

`POST /distribution/withdrawals` 请求金额只允许不超过服务端返回的可提现余额。响应 `PROCESSING` 不代表到账；前端根据 `status` 展示处理中、需要用户确认、成功或失败。后端通过微信回调/查询改变最终状态。

## 6. 联调数据

开发环境提供可重复初始化的数据集：三张轮播、八个入口、每类至少一个商品、一个多章节课程、半年/一年会员计划、三种试卷文件、实体书库存、一个分销员和可回放支付/退款/提现回调。测试数据使用明确的 `DEV-` 前缀，不得连接生产商户。

**2026-10-14 分销状态补充：** `GET /distribution/summary` 增补 `status`（ACTIVE/DISABLED）与 `receiptReady`（boolean），余额/限额/withdrawalEnabled/disabledReason原义不变。收款绑定与可提现能力不能互相推导；旧响应缺receiptReady的客户端显示“绑定状态待确认”。顾客无分销档案的summary/commissions/withdrawals及收款绑定返回404 `DISTRIBUTOR_NOT_ENABLED`；绑定被停用档案返回403 `DISTRIBUTOR_DISABLED`，优先于渠道未就绪。缺档案不自动创建，停用保留本人历史查询。真实绑定成功及商家转账出款需正式渠道独立验收。

联调报告至少记录：环境、接口版本、requestId、测试用户、订单号（脱敏）、预期/实际状态和复现步骤。真实支付、真实提现和真实用户数据禁止写进仓库。

## 7. 变更流程

后端提交接口变更时同时更新 OpenAPI、DTO 示例、错误码和迁移说明；前端确认受影响页面和兼容策略。破坏性变更增加 `/api/v2` 或保留兼容字段到前端完成切换。每个阶段验收前冻结该阶段接口字段。

## 8. DTO 基线

字段必填，除标 `?` 者可缺省；显式没有值用 null，列表无数据用 []。客户端不得根据 ID 数值大小判断类型。所有返回价格都由服务端计算；下面是设计示例，不是已部署接口返回。

```typescript
type Id = string;
type IsoTime = string;
type MoneyFen = number; // 安全整数，金额上限须在业务校验内
type ProductType = 'COURSE' | 'BOOK' | 'MEMBERSHIP';
type OrderStatus = 'PENDING_PAYMENT' | 'PAID' | 'COMPLETED' | 'CANCELLED';
type FulfillmentStatus = 'NOT_REQUIRED' | 'PENDING_SHIPMENT' | 'SHIPPED' | 'RECEIVED';
type RefundStatus = 'NONE' | 'REQUESTED' | 'RETURN_REQUIRED' | 'RETURNING' | 'PROCESSING' | 'PARTIAL' | 'FULL' | 'REJECTED' | 'FAILED';
type WithdrawalStatus = 'REQUESTED' | 'PROCESSING' | 'UNKNOWN' | 'USER_ACTION_REQUIRED' | 'SUCCEEDED' | 'FAILED' | 'CLOSED';
interface Page<T> { items: T[]; page: number; pageSize: number; total: number; }
interface AssetSummary { id: Id; name: string; extension: string; mime: string; bytes: number; }
interface ProductCard {
  id: Id; type: ProductType; title: string; coverUrl: string | null;
  priceFen: MoneyFen; originalPriceFen: MoneyFen | null;
  status: 'ON_SALE' | 'OFF_SALE'; subtitle: string | null;
}
interface Target {
  type: 'PRODUCT' | 'PRODUCT_LIST' | 'MEMBERSHIP' | 'PAPER_LIST' | 'ARTICLE';
  id: Id | null; filters: Record<string,string>;
}
interface HomeView {
  revision: number;
  banners: { id: Id; imageUrl: string; title: string; target: Target }[];
  shortcuts: { id: Id; label: string; iconUrl: string; target: Target }[];
  sections: { id: Id; type: 'PRODUCT_GRID' | 'MEMBERSHIP_ENTRY' | 'ARTICLE_CARD';
    title: string; moreTarget: Target | null; products: ProductCard[];
    article: { id: Id; title: string; coverUrl: string | null } | null }[];
}
interface MembershipView {
  level: 'STANDARD'; state: 'NONE' | 'ACTIVE' | 'EXPIRED';
  startsAt: IsoTime | null; expiresAt: IsoTime | null;
  canDownload: boolean;
  plans: { productId: Id; durationMonths: 6 | 12; priceFen: MoneyFen; projectedExpiresAt: IsoTime }[];
}
interface OrderView {
  id: Id; orderNo: string; orderStatus: OrderStatus;
  fulfillmentStatus: FulfillmentStatus; refundStatus: RefundStatus;
  goodsAmountFen: MoneyFen; freightAmountFen: MoneyFen;
  payableAmountFen: MoneyFen; paidAmountFen: MoneyFen; refundedAmountFen: MoneyFen;
  expiresAt: IsoTime | null; paidAt: IsoTime | null; completedAt: IsoTime | null;
  item: { productId: Id; type: ProductType; title: string; coverUrl: string | null; quantity: number; unitPriceFen: MoneyFen };
  allowedActions: ('PAY'|'CANCEL'|'CONFIRM_RECEIPT'|'APPLY_AFTERSALE'|'VIEW_LOGISTICS'|'VIEW_CONTENT')[];
}
interface WithdrawalView {
  id: Id; withdrawalNo: string; amountFen: MoneyFen; status: WithdrawalStatus;
  createdAt: IsoTime; successAt: IsoTime | null; failReason: string | null;
  confirmation: null | { action: 'WECHAT_CONFIRM_RECEIPT'; merchantId: string; appId: string; packageInfo: string };
}
```

金额字段语义名称固定：商品 priceFen，订单 payableAmountFen，提现 amountFen，比例 rateBps。概览中提到 amountFen 是通用“分”类型说明，不意味着所有金额都同名。图文正文统一 contentBlocks（TEXT/IMAGE，IMAGE 引用 assetId 和公开 URL），服务端白名单处理，管理端编辑器适配，不强制小程序解析平台私有富文本。

## 9. 关键请求/响应示例

### 9.1 登录与会话

`POST /auth/dev-login` 请求 `{"fixture":"buyer-active-member"}`，只接受预置测试身份，不能任意指定生产用户。`POST /auth/wechat-login` 请求 `{"code":"微信临时code"}`；响应 data 为 `{"accessToken":"opaque-token","expiresAt":"2026-10-13T12:00:00Z","user":{"id":"1001","nickname":"用户","distributor":false}}`。顾客默认7天有效、后台8小时（配置项），过期重登；POST /auth/logout 撤销会话。不要把微信 session_key 当成业务token。

### 9.2 商品、试卷搜索

- `GET /products?type=BOOK&keyword=作文&categoryId=12&sort=PRICE_ASC&page=1&pageSize=20`；sort=DEFAULT/PRICE_ASC/PRICE_DESC/NEWEST。最大 pageSize=100，重复字段拒绝，空关键词允许作为普通列表。
- `GET /papers?keyword=作文&grade=9&year=2026&subject=CHINESE&page=1&pageSize=20`。试卷是内容类型，前端搜索页“试卷”tab 调 papers，不传不存在的商品类型。
- `GET /products/{id}` 在 ProductCard 基础上附 contentBlocks、version、allowedActions，以及 course/book/membership 三个类型分支中唯一一个；book 有 availableStock、quantityLimit、shippingSummary；course 有 courseId、validityType、validityDays、entitlement、chaptersSummary；membership 有 durationMonths。
- `GET /articles/{id}` 只返回发布公开图文。`GET /papers/{id}` 返回公开摘要、attachments（AssetSummary+canPreview/canDownload），不含私有存储key。

### 9.3 下单与支付

```json
{"productId":"2001","quantity":2,"addressId":"3001"}
```

以上为 POST /orders/preview 请求。示例响应 data：

```json
{
  "quoteId":"q_JXSC_demo","expiresAt":"2026-10-06T12:05:00Z",
  "item":{"productId":"2001","type":"BOOK","title":"作文训练册","quantity":2,"unitPriceFen":3990},
  "goodsAmountFen":7980,"freightAmountFen":600,"payableAmountFen":8580,
  "currency":"CNY","warnings":[]
}
```

POST /orders 请求 `{"quoteId":"q_JXSC_demo","attributionToken":null}`，响应 OrderView。POST /payments/wechat/prepay 请求 `{"orderId":"4001"}`，响应 `{"provider":"WECHAT_PAY","paymentId":"5001","params":{"timeStamp":"...","nonceStr":"...","package":"prepay_id=...","signType":"RSA","paySign":"..."}}`。实际签名值只由服务器创建。数字商品若需不同官方支付产品，阶段0确认并保留 provider 分支；不能直接复用图书支付作未验证承诺。

开发端 `POST /dev/orders/{id}/pay`，body `{"scenario":"SUCCESS"}`，只在开发环境处理 DEV订单，与真实notify处理隔离。完成前端支付交互后 GET /orders/{id} 查状态，最多短轮询5次，此后提供手动刷新。

### 9.4 文件与课程

`POST /papers/{id}/files/{fileId}/authorize` 请求 `{"action":"DOWNLOAD"}`（或PREVIEW），响应 data `{"file":{"id":"6101","name":"示例试卷.pdf","extension":"PDF","mime":"application/pdf","bytes":10240},"url":"https://private-cdn.example/signed-url","expiresAt":"2026-10-06T12:02:00Z"}`。此URL为格式示例，不是可访问的真实资源。

课程章节列表返回 id/title/durationSeconds/isTrial/canPlay/lastPositionSeconds；play-url 返回 url/expiresAt/resumeSeconds。PUT progress 请求 `{"positionSeconds":90,"completed":false}`，后端把进度限制在章节时长，不接受任意完成权限或收益数据。播放进度不改变支付权益。

### 9.5 分享、佣金和提现

- POST /distribution/referral-codes 请求 `{"productId":"2001"}`，返回 code、miniProgramPath、imageUrl（开发期二维码可为null）。
- REAL 模式返回正式小程序码图片地址，`miniProgramPath` 保留商品 `id` 与 `scene`；同商品/分销员复用有效码至首次创建后30天。图片地址为相对 API 路径，前端功能负责人按 API origin 解析；GET `/referrals/{code}/image` 公开读取缓存 PNG，不触发微信生成，过期/禁用码或无效推广资格拒绝。生成失败返回明确错误，配置与正式扫码限制见 [部署维护](../backend/docs/deployment.md)。
- POST /referrals/resolve（公开，可选登录）请求 `{"code":"短码","visitorKey":"随机本地标识"}`，返回 productId、attributionToken、expiresAt；登录后POST /referrals/claim绑定token，后端防伪并只绑定本人。
- GET /distribution/summary 返回 pendingFen、availableFen、withdrawingFen、paidOutFen、debtFen、withdrawalEnabled、disabledReason、limits（minFen/maxFen/dailyMaxCount）、指定可推广商品数。
- POST /distribution/withdrawals 请求 `{"amountFen":1000}` + Idempotency-Key；返回 WithdrawalView。不得接收客户端指定的openid或“已到账”。
- GET /distribution/withdrawals/{id}、POST /distribution/withdrawals/{id}/refresh 查本人状态，refresh限流且仅触发原单查单，不新建转账。需要收款确认时返回 confirmation；该字段不记录日志，不发给别人。

## 10. 补充操作端点与权限

下表补充两份需求中的概览，使按钮有明确接口；所有列表使用统一分页。未列的管理端字段按实体DTO由OpenAPI补齐，但禁止私自新增业务流程。

| 范围 | 方法和路径（加 /api/v1） | 权限/用途 |
|---|---|---|
| 公共 | GET /config/public | 商城名、客服、公开协议版本、允许的格式；不返回秘密 |
| 会话 | GET /me，POST /auth/logout | 当前用户/撤销 |
| 地址 | GET/POST /addresses，PATCH/DELETE /addresses/{id} | 本人，isDefault字段由事务保证唯一 |
| 订单筛选 | GET /orders?tab=ALL/UNPAID/UNSHIPPED/SHIPPING/COMPLETED/AFTERSALE | tab由三个状态映射；afterSale包含历史退款 |
| 收货 | POST /orders/{id}/confirm-receipt | 本人且已发货；自动收货默认发货后15天，无活跃售后 |
| 售后 | POST /orders/{id}/refund，GET /aftersales/{id} | 本人申请/查询；body type/reason/evidenceAssetIds |
| 退货 | POST /aftersales/{id}/return-shipment | 本人，carrierCode/trackingNo，先获批准 |
| 幂等查询 | GET /operations/{key}?scope=CREATE_ORDER | 当前actor+scope；返回PROCESSING/SUCCEEDED/FAILED及resourceId；其他scope见OpenAPI |
| 账户后台 | POST /admin/auth/login，GET /admin/me，POST /admin/auth/logout | loginName/password；返回token/permissions |
| 首页 | GET/PUT /admin/home/draft，POST /admin/home/publish，GET /admin/home/preview | CONTENT_EDITOR；body含revision，409提示并发冲突 |
| 内容后台 | GET/POST /admin/{products,categories,courses,papers,articles}，GET/PATCH /admin/{resource}/{id} | CONTENT_EDITOR；实际路径逐项生成OpenAPI，不接受任意resource动态映射 |
| 章节 | GET/POST /admin/courses/{id}/chapters，PATCH /admin/chapters/{id}，PUT /admin/courses/{id}/chapter-order | CONTENT_EDITOR；排序列表chapters+version |
| 上下架 | POST /admin/products/{id}/publish，POST /admin/products/{id}/unpublish | CONTENT_EDITOR；不删除历史权益 |
| 库存 | POST /admin/products/{id}/inventory-adjustments | ORDER_OPERATOR；delta、reason，不能侵占锁库 |
| 上传 | POST /admin/files/presign，POST /admin/files/{id}/complete | CONTENT_EDITOR；用途限制；售后图片用 POST /files/presign，以及 /files/{id}/complete，仅当前用户 AFTERSALE_EVIDENCE |
| 后台订单 | GET /admin/orders，GET /admin/orders/{id} | ORDER_OPERATOR；订单号、日期、三种状态筛选 |
| 发货 | POST /admin/orders/{id}/ship | ORDER_OPERATOR；carrierCode/trackingNo/version/reason |
| 售后后台 | GET /admin/aftersales，POST /admin/aftersales/{id}/preview-decision，POST /admin/aftersales/{id}/approve或reject | FINANCE_OPERATOR；批准含goodsRefundFen/freightRefundFen，preview显示权益与佣金影响 |
| 收到退货 | POST /admin/aftersales/{id}/receive-return | ORDER_OPERATOR；returnedQuantity及库存入库；财务批准后才退款 |
| 会员管理 | GET /admin/membership/records，PATCH /admin/membership/plans/{id} | 内容角色改套餐；无直接改用户到期日接口，异常调整需专门审计事件 |
| 分销员 | GET/POST /admin/distributors，PATCH /admin/distributors/{id} | DISTRIBUTION_OPERATOR；后台从已有用户指定 |
| 商品分销 | GET/PUT /admin/products/{id}/distributors | DISTRIBUTION_OPERATOR；rules=[distributorId,rateBps,enabled]，version防覆盖 |
| 提现 | GET /admin/withdrawals，GET /admin/withdrawals/{id}，POST /admin/withdrawals/{id}/refresh | FINANCE_OPERATOR；无“标记成功”接口 |
| 统计/日志 | GET /admin/analytics/overview，GET /admin/analytics/trend，GET /admin/audit-logs | ANALYST/审计权限；指定日期范围 |
| 导出 | POST /admin/exports，GET /admin/exports/{id} | 对应读取+导出权限；异步生成受保护短时下载 |
| 设置 | GET/PATCH /admin/settings | SUPER_ADMIN；运营规则白名单，不返回密钥 |

外部回调固定 POST /webhooks/wechat/payments、/refunds、/transfers，按渠道验签而非用户Bearer，响应遵循渠道要求，不强行套业务envelope。地址、发货、财务操作每次均校验资源归属/权限。

## 11. 跨端联调交接标准

每阶段开始，后端提供该阶段OpenAPI、成功/失败样例及DEV数据；前端可以先用同格式fixture开发，联调时删除页面硬编码。每阶段结束双方共同记录一个可回放场景：首页发布→图书交易→课程/会员授权→分销退款/提现→真实微信。前端不直接连数据库，后端不替前端完成管理后台页面。

HTTP 200业务成功，202异步受理，400字段校验，401未登录，403无权限，404不存在，409版本/幂等/状态冲突，422业务不满足，429限流，503依赖不可用。错误字段data可附 fieldErrors/allowedActions；requestId必须可在后端日志定位。模拟环境清楚显示“开发数据”，生产不能因依赖失败返回模拟成功。

## 12. 负责人分工与并行开发规则（2026-10-08）

管理后台是初始范围，不是阶段5临时追加。前端阶段0搭建小程序与后台两个工程，后端同步准备账号/权限、数据库和API；真实AppID、支付、退款和自动提现在阶段5接入。

| 文件/任务 | 主要维护者 | 另一方如何配合 |
|---|---|---|
| frontend/miniprogram、admin、shared、assets | 前端负责人 | 后端提供字段与示例，不直接改前端组件/构建配置 |
| backend、Flyway、Java测试、渠道配置样例 | 后端负责人 | 前端报告可复现接口问题，不改表结构/领域规则 |
| 前端开发需求文档 | 前端负责人 | 涉及业务或API变化时先与后端对齐 |
| 后端开发需求文档 | 后端负责人 | 涉及交互/展示变化时通知前端 |
| 本共享契约与后端OpenAPI | 后端负责人统一整理，双方核对 | 前端提出字段需求与差异，后端合并约定，前端同步类型/fixtures |
| README、根配置、共享运行脚本 | 变更发起人先说明范围，避免同时修改 | 没有需要时保持不动；冲突由双方核对后解决，不覆盖别人工作 |

共享契约在每阶段开始冻结一版，前端使用相同结构fixtures先开发；后端按契约实现并提供成功、空数据、无权限、业务失败样例，前端逐模块切换真实接口。mock/真实环境显式选择，不在真实API报错后静默回退到mock。前端自己的普通界面修改和后端内部实现不需要逐项互相等待。

会影响另一方的修改先写清接口/字段/类型/状态、受影响页面、兼容方式与交付阶段，再同步本文件和OpenAPI。已冻结的接口优先新增兼容字段，删除/重命名必须双方安排切换。前端不临时创造金额/权限/到账规则，后端不擅自新增客户没有提出的页面或平台对接。

建议两人各自分支和独立工作目录，在自己范围提交；不要同时在一个工作目录切分支、重置或覆盖文件。只拉取自己的分支不代表可以忽略共享契约变更。每阶段联调按同一版本、同一数据集检查，记录请求ID/业务单号/预期和实际结果，不以“我的页面能打开”或“接口返回200”替代链路验收。

## 13. 经营数据共享字段（首期）

GET /api/v1/admin/analytics/overview 与 /trend 均接收 startDate、endDate（YYYY-MM-DD，结束日包含在内）。按Asia/Shanghai换算 [开始日00:00,结束日次日00:00)。查询需ANALYST或SUPER_ADMIN权限；页面没有权限时显示无权限状态，不假装数据为0。

overview 的 data 结构：

```typescript
interface AnalyticsOverview {
  period: { startDate: string; endDate: string; timezone: 'Asia/Shanghai' };
  generatedAt: IsoTime; // 统计响应生成时间，不代表所有渠道事件实时到达
  environment: 'dev' | 'test' | 'prod';
  includesDevChannel: boolean; // 仅开发/测试允许true，生产为false
  periodMetrics: {
    orderCreatedCount: number;
    paidOrderCount: number;
    paidUserCount: number;
    receivedAmountFen: MoneyFen;
    refundedAmountFen: MoneyFen;
    netCashAmountFen: MoneyFen; // 实收-退款，可负，不是利润
    courseSoldQuantity: number;
    bookSoldQuantity: number;
    membershipNewPurchaseCount: number;
    membershipRenewalCount: number;
    commissionEarnedFen: MoneyFen;
    commissionReversedFen: MoneyFen;
    withdrawalSucceededFen: MoneyFen;
  };
  currentMetrics: { // generatedAt时点快照，不能标为“区间新增”
    activeMemberCount: number;
    waitingShipmentOrderCount: number;
    pendingCommissionFen: MoneyFen;
    availableCommissionFen: MoneyFen;
    withdrawingFen: MoneyFen;
    debtFen: MoneyFen;
  };
}
interface AnalyticsTrend {
  period: { startDate: string; endDate: string; timezone: 'Asia/Shanghai' };
  generatedAt: IsoTime;
  environment: 'dev' | 'test' | 'prod';
  includesDevChannel: boolean;
  items: {
    date: string; // YYYY-MM-DD，升序；区间内没有交易的日补真实0
    orderCreatedCount: number;
    paidOrderCount: number;
    receivedAmountFen: MoneyFen;
    refundedAmountFen: MoneyFen;
    netCashAmountFen: MoneyFen;
  }[];
}
```

所有金额均为整数分，超出JS安全整数范围时拒绝不安全响应并调整业务限额/协议，不把BIGINT直接转浮点数。开发环境可显式包含DEV单以便联调，生产排除DEV交易及其关联佣金/会员/提现数据。currentMetrics按相同环境口径计算。公开会员权限等业务查询不受统计筛选开关影响。

后端落地约定（2026-10-08）：两接口新增可选 `includeDevChannel=false`，仅dev/test允许显式true；prod/未知环境请求true返回400 `VALIDATION_ERROR`。日期区间上限366天。金额超出JS安全整数范围返回422 `ANALYTICS_RANGE_EXCEEDED`，不返回部分/截断统计。响应保留既有扁平统计与下载明细字段供兼容，新增字段以本节定义为准；异步ANALYTICS导出继续采用标量CSV列且默认排除DEV。详细环境、来源及开发首页配置见本节经营统计契约。

后端计算口径按后端文档第12节，前端按字段名显示；不得返回或伪造 visitorCount、visitCount、wechatShopSales 等尚未接入字段。创建订单、收款、退款、会员、佣金使用各自事件时间；提现仅渠道最终SUCCEEDED计成功金额，UNKNOWN不计。新购/续费计成功且权益投递完成的会员订单；下载和商品明细报表保留原需求，不因概览只列部分字段而删除。

前端实现验收：日期筛选正确传参，金额格式正确，负净额正常显示，当前余额和区间流量不混标，无权限/空态/失败完整。后端实现验收：示例订单100元次日退20元、会员到期、提现UNKNOWN转SUCCEEDED等场景符合时间与状态口径；两次相同请求在数据未变化时统计一致。联调时核对同一环境和时间窗口，不要求微信公众平台访问数与系统注册数一致。
# 2026-10-13 增量契约：FC-01 我的学习分类

`GET /api/v1/learning/courses` 增加可选查询参数 `status=IN_PROGRESS|COMPLETED|EXPIRED`，`page/pageSize` 保持既有校验与默认值。省略 status 保持全部已购课程行为；未知枚举返回 HTTP 400 / `VALIDATION_ERROR`。筛选在分页之前完成，`items` 和 `total` 使用相同分组条件，按 courseId 降序。

| 查询分组 | 服务端条件 |
| --- | --- |
| IN_PROGRESS | 课程权益 ACTIVE，且有效章节未全部完成；零有效章节归此组 |
| COMPLETED | 课程权益 ACTIVE，有效章节数大于 0，全部有效章节的进度达到当前章节时长 |
| EXPIRED | 按现有多来源权益、撤销记录和时间边界聚合后，课程权益为 EXPIRED |

响应条目的 `status` 仍是课程权益状态（NONE / ACTIVE / PENDING / EXPIRED），**不是查询分组**。NONE、PENDING 不属于这三个分组，但省略筛选时仍可出现在既有全部列表。撤销、续费、多来源和播放/进度权限继续使用现有 `EntitlementAccess`，筛选不创建或恢复权益。停用章节不计入完成度，已保存进度按当前章节时长判定，不信任旧 completed 标记。

小程序恢复学习中 / 已完成 / 已过期三个入口，实际传递 status；切换从第一页开始，拒绝旧分类迟到响应，分页失败保留已有卡片并重试原页。此前课程详情为了寻找关联商品而使用的不带 status 查询继续兼容。本次无数据库迁移，无真实付款或业务数据调整。

服务更新后须按本节契约重新验证筛选行为。
