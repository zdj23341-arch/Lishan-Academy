# 前端架构与平台边界

shared/src 处理请求、会话、金额、交易、内容、学习及分销规则，两端页面负责交互和平台生命周期。服务端最终决定权限、价格、库存、权益和资金状态。

## 导航和视觉

后台路由以 admin/src/router/index.ts 为准，小程序以 miniprogram/src/pages.json 为准。后台权限入口隐藏不能替代服务端鉴权。

公共组件在两端 src/components，样式变量在 src/styles。可编辑素材在 assets/design/lishan-v1；微信运行图标使用 PNG，后台使用 SVG。保留 Lucide 许可证。

## 微信登录和支付

当前使用者的微信客户端取得临时 code，后端通过应用的 AppID/AppSecret 换取该用户微信身份，再签发数据库会话。AppID/AppSecret 标识应用，不能用来选择用户。切换测试用户需另一微信账号扫码；模拟器使用开发者工具当前登录的微信身份。

真实登录须关闭 VITE_ENABLE_DEV_LOGIN，并将后端身份提供者设为 REAL。支付模式独立配置；真实登录不代表支付开通。

后端按订单生成支付参数，小程序调用微信能力。取消、失败及结果未知按原订单重查，前端不能宣告支付成功。H5 无法替代微信原生支付或收款确认；实际商户权限、回调和账单仍需验收。

## 课程、文件和图片

课程使用后端授权的短期播放地址；会员试卷每次预览/下载分别鉴权。页面退出、账号切换和异步回调遵守已有控制器的会话隔离。

首页当前显示课程学习记录，以服务端课程进度为依据；图书浏览和试卷下载不计入课程进度，统一学习行为记录尚未实现。

商品图片优先使用服务端 URL，失败显示组件兜底。实际加载速度受尺寸、压缩、缓存、带宽和客户端网络共同影响。

## 测试样例

dev-assets 是自制测试视频和附件，dev-tools 只在显式 mock 开发服务中提供它们。再生成脚本在 tools/generate-*.py；按脚本导入单独安装工具依赖，不影响应用运行依赖。生产内容及本地上传文件不随源码发布。
