# Original DEV media

`course-sample.mp4` is a generated colour test pattern visibly labelled `DEV TEST ONLY - 60 seconds`. It contains no course content or third-party media. H.264, 320×180, 10fps, 60 seconds, no audio; 576367 bytes; SHA-256 `bb4497cf206fe1db8bc21566ea70a39c467011a0c2850fc1d4de16303c6bac08`.

Generated by `tools/generate-course-test-video.py` using imageio-ffmpeg0.6.0 installed only into the OS temporary `jxsc-fixture-generator` directory. This is an authoring tool, not an application dependency. Regeneration refuses to overwrite an existing asset. Paper fixtures are generated by `tools/generate-paper-test-assets.py`; checksums are in `paper-test-assets-manifest.json`.

The `courseMediaPlugin` serves only `/course-sample.mp4` during explicit mock development/test serve sessions, including HEAD and byte ranges for seeking. uni-app replaces Vite's ordinary public-file middleware, so a dedicated exact-path middleware is needed. Production/build commands do not apply this plugin; this folder is outside the application source/static bundle. Local sample availability demonstrates browser playback only, not signed CDN enforcement or native-device delivery.
